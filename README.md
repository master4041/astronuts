# Astronuts — IIIT Delhi Astronomy Club

A responsive, multi-page website for Astronuts with separate Home, About, Events, Our Team and Contact pages.

## Preview locally

From this folder, run:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Open [http://127.0.0.1:4173/](http://127.0.0.1:4173/) in a browser.

## Site notes

- Content describes the club and activity formats published on the [official Astronuts website](https://astronuts.iiitd.edu.in/).
- The team page intentionally leaves names and designations out until the current roster is supplied.
- The Events page describes activity formats and does not invent event dates or an upcoming schedule.
- Contact links lead to the club's published email and social channels.
- The site is built with plain HTML, CSS and JavaScript; no package install or build step is required.
